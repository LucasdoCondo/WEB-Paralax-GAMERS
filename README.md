# WEB-Paralax-GAMERS

Loja web de produtos gamers construída com React, TypeScript e Vite. A interface reúne vitrine de produtos, navegação com efeito parallax, benefícios e carrinho de compras.

## Requisitos

- Node.js
- npm

## Instalação e desenvolvimento

```bash
npm install
npm run dev
```

O Vite informa no terminal o endereço local para abrir a aplicação.

## Build

```bash
npm run build
npm run preview
```

O primeiro comando verifica os tipos TypeScript e gera a build de produção; o segundo serve a build localmente para conferência.
